# 家庭财务管理工具

一个纯前端的家庭财务管理网页应用，所有数据存储在浏览器本地（IndexedDB），无需服务器，无需登录，完全私有化。

## 功能特性

### 📊 资产分类管理

#### 现金类流动资产
- 支付宝余额
- 各银行卡活期 + 活钱宝
- 股市流动资金

#### 稳健资产
- 定期存单（自动按到期日从近到远排序，带到期提醒）
- 公积金

#### 投资资产
- **股市**
  - A股持仓（市值、成本、盈亏计算）
  - B股持仓
- **货币理财**
  - 实时汇率换算
  - 自动核算人民币价值
- **基金**
  - 银行购买的基金
  - 支付宝购买的基金
- **理财产品**
  - 银行理财
  - 支付宝理财
- **贵金属**
  - 积存金
  - 实物黄金

#### 实物资产
- 房产
- 车辆

### 💳 负债管理
- 信用卡（额度、账单日、还款日）
- 花呗

### 🛡️ 保险管理
- 医疗保险
- 养老保险

### 📝 消费记录
- 分类记录日常消费
- 消费趋势图表
- 消费明细查询

### 📈 关键指标
- **净资产**：总资产 - 总负债
- **净资产增长率**：环比变化
- **各类投资占比**：饼图可视化
- **抗风险能力**：现金+稳健资产 / 预估月支出
- **随时间变化曲线**：净资产历史趋势

### 🔧 数据管理
- 数据完全存储在浏览器本地
- 支持数据导出（JSON备份）
- 支持数据导入（恢复备份）
- 自动记录净资产历史

## 使用方法

### 1. 直接打开

用浏览器直接打开 `index.html` 文件即可使用。

```bash
# 或者使用简单的HTTP服务器
npx serve .
# 或
python3 -m http.server 8080
```

### 2. 开始使用

1. 点击左侧导航切换不同页面
2. 点击右上角 **"+ 新增记录"** 添加资产/负债/消费
3. 定期更新股票市值、基金净值等变动数据
4. 查看"财务分析"页面获取财务健康建议

### 3. 数据备份

定期点击侧边栏的 **"导出数据"** 按钮，将财务数据备份到本地。

### 4. 数据恢复

点击 **"导入数据"**，选择之前导出的JSON文件恢复数据。

## 技术栈

- **纯 HTML + CSS + JavaScript**，无需构建工具
- **IndexedDB** 本地数据存储（via LocalForage）
- **Chart.js** 图表可视化
- 响应式设计，支持移动端

## 数据存储说明

所有数据保存在浏览器本地的 IndexedDB 中：
- 数据不会上传到任何服务器
- 清除浏览器数据会导致数据丢失，请定期导出备份
- 不同浏览器、不同设备之间的数据不互通

## 快捷键

- `Esc` - 关闭弹窗
- `Ctrl + N` - 新增记录

## 浏览器兼容性

- Chrome / Edge / Firefox / Safari 最新版
- 需要支持 IndexedDB 和 ES6+

## 注意事项

1. **汇率更新**：货币理财的汇率需要手动更新
2. **股票市值**：需要定期手动更新持仓市值
3. **定期存单**：到期日快到了会自动高亮提醒
4. **定期备份**：务必定期导出数据备份
